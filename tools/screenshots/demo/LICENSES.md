# Demo content — origin and licences

Every file under `demo/files/` and everything `workspace.json` generates exists for one purpose:
to fill the panels in the screenshots with something plausible. It is what a visitor sees in the
gallery, so its origin has to be beyond question.

## Rules

1. **Nothing here may come from a real document, project or mailbox.** It is all invented.
2. Any third-party file must be freely redistributable, and must be listed in the table below with
   its source, author and licence.
3. No file name, path or content may contain a real person's name, a host name, an e-mail address
   or anything else personal. A preflight check refuses to start a capture run when the author's
   Windows user name or computer name appears anywhere in this folder.

## Adding more photographs

Run `node .work/photos.mjs` (the script lives in the scratch folder, not in the build) or add files
by hand. **Only CC0 or public-domain material**, never a licence that requires attribution, and
never anything personal: the author's own photographs are deliberately not used here.
