# Tasks: Website Release for Tandem Commander 0.1.9

**Input**: Design documents from `/specs/009-release-0-1-9/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/digest-0.1.9.md, quickstart.md

**Tests**: No new tests are written - the spec asks for none. The existing suites and build gates
run through `npm run release:check`.

**Organization**: Tasks are grouped by user story. This is a content release: tasks run commands,
write one data file and verify generated output; no source code is written.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (read-only checks on different files, no dependency on an
  incomplete task)
- **[Story]**: User story of spec.md the task belongs to (US1 to US4)
- All paths are relative to the repository root `E:\Projects\tandemcommander-web`

## Standing rules for every task

- Work only on branch `009-release-0-1-9`. Never commit, push, merge or deploy.
- Never edit anything under `public/` by hand; it is regenerated by the build.
- Never edit `../tandemcommander` (the application repository).
- Do not edit `content/gallery/scenes.json`, `src/_data/i18n/*.json`, `src/pad.njk`, templates,
  styles, scripts, `tools/`, `lib/` or `tests/`. If a check fails for a reason outside
  `content/releases/0.1.9.json`, stop and ask the author.

## Implementation Strategy

### MVP First

1. Phases 1 to 3: confirm facts, record the approved digest
2. Phase 4: build and verify that the site presents 0.1.9 (US1)
3. **Stop and validate**: at this point the site is correct in every fact; only the five pictures
   still show 0.1.8

### Incremental Delivery

1. US3 + US1 → the site states the right version
2. US2 → the digest is verified in both languages
3. US4 → pictures re-captured, final check, handover; the release counts as done only here
   (clarification 1)

### If the capture cannot run

T014 to T018 wait for the author. Everything before them can be completed and reported; the
handover then says plainly that the release is not finished and which pictures are stale.
