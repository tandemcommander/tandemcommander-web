# Implementation Plan: PAD File for Software Catalogs

**Branch**: `005-pad-file` | **Date**: 2026-08-22 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/005-pad-file/spec.md`

## Summary

Publish a bilingual (English + Czech) PAD file at the permanent URL `https://tandemcommander.org/pad.xml`, generated by the existing Eleventy build from the site's single data source (`site.json` + i18n catalogs), validated by a build gate in the same style as the existing i18n gates, and served by the existing Cloudflare assets-only Worker. Releasing a new version through the current routine (edit `site.json`, deploy) updates the PAD automatically; the only new release datum is the installer size in bytes, recorded manually per clarification.

## Technical Context

**Language/Version**: Node.js ≥22 (local v24; wrangler requirement), Eleventy 3.x, Nunjucks templates

**Primary Dependencies**: `@11ty/eleventy` ^3.0.0 (build), `wrangler` ^4 (deploy) — **no new dependencies**

**Storage**: Files — `src/_data/site.json` (program facts, gains `installerSizeBytes`) and `src/_data/i18n/{en,cs}.json` (gain a `pad.*` namespace for descriptions/keywords)

**Testing**: Build-time gates in `eleventy.config.js` (established project pattern: i18n parity/empty-value gates); red/green scenarios in quickstart.md — the project has no test framework and this feature does not introduce one

**Target Platform**: Cloudflare Workers assets-only site (serves `./public` verbatim, atomic deploys); consumers are software-catalog PAD importers fetching `/pad.xml` over HTTP

**Project Type**: Static web site (single Eleventy project)

**Performance Goals**: N/A — one static XML file (< 10 KB) built once per deploy

**Constraints**: Build stays offline/deterministic (clarification Q1); PAD per-field character limits and enumerations; UTF-8 output; URL `/pad.xml` permanent once submitted to catalogs

**Scale/Scope**: 1 generated file, 1 new template, 1 new data helper, ~7 new i18n keys × 2 languages, 1 new `site.json` field, 1 validation gate, 1 template refactor (download.njk reuses the shared installer helper)
